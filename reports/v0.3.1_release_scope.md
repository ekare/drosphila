# FlyRot v0.3.1 release scope

## Status

This branch is the stable correctness/provenance release line. It contains
backward-compatible path-free provenance manifests, explicit pose/image
geometry and crop/resize conventions, exact homography tests, validity-aware
directional evaluation, and regression tests.

The existing v0.3 checkpoint is unchanged. This release adds no learned model
weights and makes no new learned-capability claim.

## Deliberately excluded

FlyRot-v1, the T4/T5-inspired retinotopic experimental field, SO(3) memory,
depth-conditioned translation helpers, and scale-free translation helpers are
kept on the experimental development line. They are not default behavior and
are not part of the v0.3.1 stable package.

## Provenance

The release is reproducible from the Git commit, package metadata, test
suite, wheel contents, and path-free run-manifest helpers. Local dataset roots,
hostnames, IP addresses, GPU identifiers, checkpoints generated during
experiments, and caches are not tracked by this stable release.
