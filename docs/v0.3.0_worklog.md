  `13.0248 deg`, `0.67990`, `0.68318`, and `1.0`.
- Scale calibration: 3,456 deterministic rows generated. Evidence-vs-
  displacement Spearman correlation was `-0.231` for all repeated scales;
  magnitude-aware residual was rejected for this release.
- CI change: Python 3.11/3.12 workflow added with tests, compile, build,
  wheel-content check, and dataset-free 128x128 synthetic smoke.

  `old_confidence` for the oracle summary; fixed and rerun successfully.

  fast-cache index; public docs retain only portable placeholders.
